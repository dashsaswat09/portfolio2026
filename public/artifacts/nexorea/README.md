# Artifacts for /work/nexorea

Drop images here (PNG/JPG/WebP, ideally 1600px wide, under 400 KB).
Name each file after the artifact `id` in content/case-studies.ts (e.g. `funnel.png`),
then set that artifact's `file` to `/artifacts/nexorea/<id>.png` and its status to "verified".
For Figma or Google Docs, set `href` instead of `file`.
